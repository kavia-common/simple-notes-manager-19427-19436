# Simple Notes Frontend Usage

- Configure backend URL using `NUXT_PUBLIC_NOTES_API_BASE` (e.g., `http://localhost:8000`)
- Endpoints expected:
  - GET /notes
  - POST /notes
  - GET /notes/:id
  - PUT /notes/:id
  - DELETE /notes/:id

Development
- npm install
- npm run dev

Build
- npm run build
- npm run preview
